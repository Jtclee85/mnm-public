# 뭐냐면 개인정보처리방침


## 1. 적용 범위와 운영자

뭐냐면은 자료 이해, 탐구, 발표, 글쓰기 및 성찰 활동을 돕는 교육용 웹서비스입니다. 이 방침은 서비스 이용 중 처리되는 학습 자료, 대화, 학습 기록, 교사 API 키 및 학급 정보의 처리 방법을 안내합니다.

- 개인정보처리자: 이진복
- 개인정보 보호책임자 또는 담당자: 이진복
- 개인정보 관련 문의 및 권리 행사: teacher@ice.go.kr
- 적용 서비스 주소: mnm-public.vercel.app 및 mnm-public.vercel.app/teacher

외부 사이트로 이동하여 이용하는 서비스에는 해당 사이트의 개인정보처리방침이 적용됩니다.

## 2. 처리 목적과 항목

서비스는 기능에 따라 다음 정보를 처리합니다. 이름·이메일·전화번호·주민등록번호를 입력하는 회원가입 절차는 제공하지 않습니다. 다만 자유 입력 내용과 사진에 개인정보가 포함되면 해당 정보도 처리될 수 있습니다.

| 목적 | 처리 항목 | 처리 경로 |
| --- | --- | --- |
| 자료 분석, 쉬운 설명, 질문·답변, 발표·글쓰기 지원 | 조사 주제, 입력한 자료 또는 발췌문, 학년 수준, 선택 언어, 활동 모드, 요청 내용, 요청에 포함된 이전 대화와 AI 응답 | 이용자 브라우저 → 서비스 서버 → 해당 학급에서 선택한 AI 업체. 서버 공용 키 모드에서는 OpenAI |

| 교사 AI 연결 및 학급 운영 | 선택 AI 업체, 교사 API 키, 학교 이름, 학급 코드, 생성·만료 시각, 관리 토큰 또는 그 해시 | 교사 브라우저 및 서버 학급 저장소 |

위 처리는 기능별로 [확정된 개인정보 처리의 법적 근거]에 따라 이루어집니다. 동의가 필요한 처리는 해당 동의 절차를 거쳐야 합니다.

**수업 이용 원칙은 개인정보를 입력하지 않는 것입니다.** 채팅·조사 자료·학습 기록에는 본인이나 다른 사람의 이름, 연락처 등 개인을 알아볼 수 있는 정보를 쓰지 않습니다. 사진 읽기에는 얼굴과 이름표 등 식별 정보가 보이지 않는 자료만 사용합니다.

사진의 촬영 위치 등 기존 메타데이터는 브라우저에서 이미지를 다시 만드는 과정에서 전송 이미지에 포함되지 않도록 구현되어 있습니다. 사진 속 얼굴, 이름표, 문서 등에 보이는 개인정보까지 자동으로 지워지는 것은 아닙니다. 개인정보나 민감한 내용이 들어 있는 자료는 입력하거나 촬영·전송하지 말아 주세요.

## 3. AI 서비스 이용과 전송

학급 기능을 사용하는 경우 교사가 Gemini 또는 OpenAI를 선택하고 자신의 API 키를 등록합니다. 학생은 학급 코드로 연결하며 교사의 API 키를 전달받지 않습니다. 별도의 서버 공용 키 모드에서는 서버에 설정된 OpenAI 키를 사용합니다.

AI 요청에는 답변을 만드는 데 필요한 지시문과 학습 맥락이 포함됩니다. 학습 메모도 성찰·평어 등 해당 기능을 요청하면 전송될 수 있으므로, 메모가 항상 기기에만 남는 것은 아닙니다. 이미지 글자 추출을 요청하면 사진 이미지 자체가 AI 업체로 전송됩니다. OpenAI 이용 시에는 안전성 확인을 위한 별도 Moderation API 요청이 이루어질 수 있습니다.

AI 업체의 입력·출력 보관 및 모델 개선 이용 조건은 업체와 계약·계정 설정에 따라 달라집니다. 모든 요청이 즉시 삭제되거나 모델 학습에 절대 사용되지 않는다고 일괄 보장하지 않습니다. 적용되는 업체·계정 조건과 국외 이전 내역은 제8조의 확정된 안내를 확인해 주세요.

## 4. 학습 기록의 저장과 삭제

학습 기록은 사용 중인 브라우저의 로컬 저장소에 주제별로 저장됩니다. 동일한 기기·브라우저를 다른 사람이 이용하면 해당 기록을 볼 수 있습니다. 다른 기기나 브라우저로 자동 동기화하는 학습 기록 기능은 제공하지 않습니다.

학습 기록에는 정해진 자동 삭제 기한이 없습니다. 저장된 주제 삭제 기능으로 해당 주제의 저장 기록과 메모를 삭제할 수 있고, 브라우저의 해당 사이트 데이터 삭제 기능으로 남아 있는 학습 기록, 임시 메모 및 설정을 지울 수 있습니다. 브라우저를 닫는 것만으로 로컬 저장소가 삭제되지는 않습니다.

기기에서 기록을 삭제하더라도 이미 AI 업체로 전송된 데이터, 별도 수집 서버에 제출된 산출물, 다른 사람에게 전달된 공유 링크나 내려받은 파일이 함께 삭제되는 것은 아닙니다.

## 5. 교사 API 키와 학급 정보

교사의 API 키는 기본적으로 해당 탭의 세션 저장소에 저장됩니다. ‘이 기기에 저장’을 선택하면 브라우저의 로컬 저장소에 보관됩니다. 브라우저 저장소의 키는 서버 학급 저장소의 암호화 방식과 달리 별도 암호화하여 저장하는 구조가 아니므로, 공용 기기에서는 저장 여부와 사용 후 삭제에 주의해 주세요. 브라우저의 세션 복원 방식에 따라 종료 후 세션 저장소가 복원될 수 있습니다.

학급을 만들면 서버 학급 저장소에 학교 이름, 선택 AI 업체, 암호화한 API 키, 관리 토큰의 해시, 생성·만료 시각을 저장합니다. 학급 코드에는 학교 이름이 포함됩니다. 관리 토큰 원문은 교사 기기의 로컬 저장소에 보관하며, 교사 기기에서 학급 키 교체와 삭제 권한을 확인하는 데 사용합니다.

학급은 생성한 날의 다음 한국 시간 자정에 이용이 만료됩니다. 서버 기록에는 해당 시각까지의 자동 만료 시간이 설정되며, 자정 직전 생성 시에는 최소 60초의 저장 만료 시간이 적용될 수 있습니다. 이용 권한은 기록의 만료 시각을 기준으로 확인합니다. 교사가 학급 삭제를 실행하면 서버의 해당 학급 기록을 삭제합니다. 저장 업체의 백업·로그까지 같은 시점에 지워지는지는 별도의 운영 보존 안내에 따릅니다.

API 키를 기기에서 삭제하는 것과 서버 학급을 삭제하는 것은 서로 다릅니다. 키 사용을 중단하려면 필요한 학급 삭제와 키 삭제를 각각 수행하고, 키 유출이 의심되면 발급 업체에서도 키를 폐기해 주세요. 학급 삭제는 학생 기기의 학습 기록을 삭제하지 않습니다.

학급 코드 오입력을 제한하기 위해 접속 IP로부터 해시 식별값을 계산하고 실패 횟수를 저장합니다. 실패 횟수 기록에는 최초 실패로부터 10분의 만료 시간이 설정됩니다. 이 해시 기록을 개인과 무관한 완전한 익명정보로 간주하지 않습니다.

## 6. 공유 링크와 선택적 산출물 수집

공유 기능은 학생 작성 내용과 일부 보조 자료를 URL에 넣어 전달합니다. 해당 URL을 가진 사람은 별도 로그인 없이 내용을 확인할 수 있습니다. URL의 인코딩은 암호화가 아니며, 링크는 브라우저 방문 기록이나 링크를 전달한 서비스 등에 남을 수 있습니다.

공유 링크에는 자동 만료나 개별 회수 기능이 없습니다. 링크를 전달하기 전에 학생 이름, 연락처, 학교·학급에서 개인을 알아볼 수 있는 내용 등을 확인해 주세요.

현재 서비스는 공유 URL을 생성할 때 학습 산출물을 별도 수집 서버로 전송합니다. 전송 항목은 임의 생성 사용자 ID, 산출물 ID, 전송 시각, 앱 식별값·버전, 활동 모드, 주제, 이해·탐구·발표·글쓰기의 학생 작성 내용입니다. 이 경로는 AI 대화 전체·원본 자료 전체·AI 쉬운 설명을 전송하도록 구성되어 있지 않습니다. 그러나 학생이 작성 내용에 개인정보를 입력하면 그 내용은 포함될 수 있습니다. 임의 생성 ID 사용만으로 완전한 익명성이 보장되는 것은 아닙니다.


## 7. 브라우저 저장소, 쿠키 및 로그

서비스는 학습 기록, 학급 연결 정보, 교사 학급 관리 정보, 선택적으로 저장한 API 키, 튜토리얼 표시 여부, 임의 생성 사용자 ID, 산출물 중복 전송 확인 정보, 추천 영상 캐시 등을 브라우저 저장소에 보관합니다. 산출물 중복 전송 확인 정보는 최근 항목 최대 50개를 유지하며, 시간에 따른 자동 삭제 기한은 없습니다.

추천 영상 캐시는 일반 결과 24시간, 결과 없음 15분, 사용량 제한 시 30분 이상 등의 유효기간을 적용합니다. 유효기간 경과는 재사용 중단을 뜻하며, 저장된 값이 그 시각에 즉시 지워짐을 뜻하지 않습니다.

확인한 애플리케이션 코드에는 자체 로그인·광고 추적용 쿠키를 설정하는 기능이 없습니다. 다만 실제 호스팅 환경이나 외부 서비스의 쿠키·로그 처리까지 없다는 의미는 아닙니다. 브라우저에서 사이트 저장을 차단하거나 사이트 데이터를 삭제할 수 있으며, 이 경우 학습 이어하기나 학급 관리 기능이 제한될 수 있습니다.

서비스 장애 확인과 보안 대응을 위한 운영자 로그의 보관 기준은 기록일로부터 1년입니다. 이 기준과 별도로 Vercel Hobby의 기본 실행 로그는 1시간 동안 조회할 수 있습니다. 기본 실행 로그에는 요청 경로, 요청 시각, HTTP 상태 및 함수에서 기록한 메시지 등이 포함됩니다. [Vercel 실행 로그 안내](https://vercel.com/docs/logs/runtime) 앱은 AI 처리 오류의 분류 코드와 상태를 기록하며, 추천 영상 기능에서 검색 주제 또는 오류 정보가 기록될 수 있습니다. 공유 내용과 영상 검색 주제는 요청 URL에 포함될 수 있습니다.

외부 영상 썸네일이 표시되면 해당 이미지 제공 서버에 네트워크 요청이 발생합니다. YouTube 링크를 열거나 지원되는 데모 모드에서 영상 미리보기를 실행하면 해당 서비스와 연결됩니다. 외부 글꼴을 불러오도록 작성된 스타일 코드도 있습니다. 외부 요청에는 통신에 필요한 접속 정보가 전달될 수 있습니다.

## 8. 외부 업체, 제3자 제공, 처리위탁 및 국외 이전

**AI 업체에 전달하는 정보**

교사가 선택한 공급자에 따라 Google Gemini API 또는 OpenAI API로 자료를 보냅니다. 자료 분석이나 채팅을 요청하면 질문, 조사 주제·자료, 답변에 필요한 이전 대화가 전달됩니다. 사진 읽기를 요청하면 크기를 조정한 사진이 전달됩니다. 이름·연락처가 적힌 글이나 얼굴·이름표가 보이는 사진은 그 정보까지 함께 전달될 수 있으므로 입력하거나 전송하지 말아 주세요.

**제3자 제공과 관련된 무료 Gemini 이용 조건**

무료 Gemini API를 선택한 경우 위 자료는 답변 생성이나 사진 글자 추출을 위해 Google에 전송됩니다. Google은 무료 서비스에 제출한 입력과 생성 결과를 자사 제품·서비스 개선에도 이용할 수 있으며, 무료 서비스에 개인정보를 제출하지 말라고 안내합니다. 제품 개선 목적의 보유기간은 아래의 악용 감시용 55일과 구분됩니다. 개인정보를 Google의 제품 개선에 제공하는 데 동의하는 절차는 현재 서비스에 마련되어 있지 않습니다. [Gemini API 약관](https://ai.google.dev/gemini-api/terms)

**외부 업체에 맡기는 운영 업무**

- **Vercel**은 웹페이지와 API를 호스팅하고 이용자의 요청을 처리합니다. 접속·요청 정보 및 오류 기록이 처리될 수 있습니다. 현재 무료 요금제(Hobby)를 이용합니다. Vercel이 공개한 데이터 처리 부속계약은 Pro와 Enterprise의 수탁 처리에 적용됩니다. [Vercel 데이터 처리 조건](https://vercel.com/legal/dpa)
- **Upstash**는 학급 코드 운영에 필요한 학교 이름, AI 공급자, 암호화한 교사 API 키, 관리 토큰 해시, 생성·만료 시각과 오입력 제한 기록을 저장합니다. 학급 저장소는 일본 도쿄에 있으며, 학급 기록과 오입력 기록의 만료 기준은 제5조에 따릅니다.
- **유료 Gemini API와 OpenAI API**는 요청에 따라 답변 생성 또는 사진 글자 추출을 수행합니다. 교사가 등록한 프로젝트나 계정에 해당 데이터 처리 계약이 적용되는 경우, 그 계약에 따라 서비스 제공에 필요한 범위에서 자료를 처리합니다. [Gemini API 약관](https://ai.google.dev/gemini-api/terms) · [OpenAI 데이터 처리 계약](https://openai.com/policies/data-processing-addendum/)

추천 영상 검색어는 YouTube Data API에 전달되며, 영상·이미지와 외부 글꼴을 불러올 때 해당 서버로 접속 요청이 발생할 수 있습니다. 별도 산출물 수집은 현재 사용 중이며, 수집 항목은 제6조에 따릅니다.

AI 업체의 보관 기준은 다음과 같습니다. 이 기간은 뭐냐면 운영 로그의 1년 보관과 별개입니다.

- Gemini API는 악용 감시를 위해 프롬프트, 함께 보낸 맥락 정보, 생성 결과를 55일간 보관한다고 안내합니다. 무료 서비스의 제품 개선 이용과 프로젝트에 별도로 설정한 로그·데이터세트에는 각각의 조건이 적용됩니다. [악용 감시 정책](https://ai.google.dev/gemini-api/docs/usage-policies) · [Gemini API 약관](https://ai.google.dev/gemini-api/terms) · [프로젝트 로그 정책](https://ai.google.dev/gemini-api/docs/logs-policy)
- OpenAI Chat Completions API는 기본적으로 입력·출력이 포함될 수 있는 악용 감시 로그를 최대 30일간 보관합니다. 법률상 보관이 필요하거나 안전을 위해 더 오래 보관하는 예외가 있으며, 승인된 데이터 보관 설정과 이미지 안전 검토에도 별도 조건이 적용됩니다. [OpenAI API 데이터 보관 정책](https://developers.openai.com/api/docs/guides/your-data)

업체가 개인정보를 해외에서 처리하거나 보관하는 경우에는 국외 이전에 해당할 수 있습니다. 이전 국가와 추가 보관 조건은 실제 프로젝트 설정과 계약에 따라 달라집니다. 브라우저에서 학습 기록을 삭제하는 것만으로 외부 업체의 보관 정보까지 삭제되지는 않습니다.

## 9. 안전성 확보 조치

학급 API 키는 서버 학급 저장소에 넣기 전에 AES-GCM 방식으로 암호화하고, 암호화 비밀값은 서버 환경변수에서 관리하도록 구성되어 있습니다. 서버는 학급 관리 토큰 원문 대신 해시를 저장하고, 학급의 만료 시각과 관리 권한을 확인합니다. 학급 응답은 캐시되지 않도록 설정하고, 학급 코드 오입력 제한을 적용합니다.


## 10. 이용자와 법정대리인의 권리

이용자와 법정대리인은 관계 법령에 따라 개인정보의 열람, 정정·삭제, 처리정지 및 동의 철회 등을 요구할 수 있습니다. 권리 행사는 제1조의 연락처로 요청할 수 있으며, 운영자는 요청자 또는 대리인의 권한을 확인하는 데 필요한 최소한의 정보를 확인합니다. 법령에 따라 요구가 제한되는 경우 그 사유를 안내합니다.

브라우저에만 저장된 기록은 해당 기기에서 직접 삭제할 수 있습니다. 별도 서버에 제출된 산출물의 삭제를 요청할 때는 보유하고 있는 산출물 ID 등 확인 정보를 함께 알려 주세요. 외부에 전달·복제된 링크나 파일은 수신자 또는 해당 서비스에도 삭제를 요청해야 할 수 있습니다.

**학교 수업에서 만 14세 미만 학생이 이용하는 절차**

학교는 수업 전에 가정에 이용 목적, 처리하는 정보, 외부 AI 전송과 산출물 수집, 보관 기간을 안내합니다. 법정대리인 동의가 필요한 경우 담임교사는 학교의 기존 안내·회신 절차로 법정대리인이 동의했는지 확인한 뒤, 동의가 확인된 학생에게만 학급 코드와 접속 주소를 개별 배포합니다. 학생은 코드를 다른 사람에게 전달하지 않습니다.

학교가 동의 기록을 관리합니다. 뭐냐면에서는 학생 회원가입을 받지 않으며, 학교의 학생 명단이나 동의서를 별도로 제출받지 않습니다. 동의하지 않거나 철회한 학생은 코드 배포와 해당 활동에서 제외합니다. 이미 배포한 공용 코드로 계속 접속할 수 있는 경우 담임교사는 기존 학급 코드를 삭제하거나 재발급하고, 새 코드는 이용할 수 있는 학생에게만 전달합니다. 동의 철회는 담임교사를 통해 요청할 수 있으며, 개인정보 권리 행사는 제1조의 연락처로도 요청할 수 있습니다.

**가정에 보내는 안내문 예시**

- **이용 목적**. 사회과 조사학습에서 자료 이해, 탐구 질문 만들기, 발표·글쓰기 준비에 뭐냐면을 사용합니다.
- **처리 항목과 전송**. 학생이 입력한 주제·자료·질문과 답변에 필요한 이전 대화를 수업에 사용하는 AI 업체에 보냅니다. 사진 읽기를 쓰면 사진도 보냅니다. 공유 링크를 만들면 임의 생성 ID와 학생 작성 산출물이 별도 수집 서버로 전송됩니다. 이름, 연락처, 얼굴이나 이름표가 들어간 글·사진은 올리지 않도록 지도합니다.
- **수업에서 적용할 조건**. 학교는 이용 기간, 사용할 AI 업체와 적용 계정 조건, 실제 보관 기간, 문의처를 채워 안내합니다. 산출물 보관 기준은 제11조에 따릅니다. 제3자 제공이나 국외 이전에 별도 동의가 필요한 경우에는 해당 내용을 안내하고 별도로 동의를 받습니다.
- **동의 선택과 철회**. 법정대리인은 학교가 지정한 회신 방법으로 동의 여부를 선택할 수 있습니다. 동의하지 않거나 철회하면 해당 앱 활동 참여가 제한됩니다. 철회와 문의는 담임교사에게 요청할 수 있습니다.


## 11. 보유 기간과 파기

- 운영자가 적용하는 로그 보관 기준은 기록일로부터 1년입니다. Vercel 기본 실행 로그의 조회 기간과 항목은 제7조에서 안내합니다.
- 서버 학급 기록은 한국 시간으로 생성일이 끝나는 자정에 이용이 만료됩니다. 자정 직전에 생성한 기록의 최소 저장 만료 시간과 교사의 직접 삭제 방식은 제5조에서 안내합니다.

- 기기 내 정보와 공유 링크에는 제4조부터 제7조의 삭제·만료 방식이 적용됩니다. 외부 AI의 보관 조건은 제8조에서 안내합니다.
